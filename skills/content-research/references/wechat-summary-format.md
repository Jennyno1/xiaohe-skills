# 微信摘要版格式规范（v8.0 用户拍板）

> 来源：2026-08-28/29 用户两次纠正「太冗长了」「内容和上个版本没啥改变」。本文件是微信摘要版的权威格式规范。

## 核心原则

**600 CJK 字以内，结构对齐完整版（去掉📖推荐阅读），每段一句话扫读。**

## 硬性规则

### 1. 字数上限
- **≤600 CJK 字**（check 脚本统计）
- 宁短勿长，信息密度 > 篇幅

### 2. 结构对齐完整版
- 🎯→🎨→💼→🤖→⭐→📊 六段式，**去掉📖推荐阅读**
- 每个赛道保留 📌🔍💡 三段式，但每段压缩到 1-2 句话

### 3. 🎯 今天要点
- **3 条 • 列表，每条一行，纯短句**
- **禁止括号补充说明**（如"（OpenAI Jalapeño 自研推理芯片、Amazon 三倍追加 NVIDIA 订单）"）
- 每条 ≤35 字

### 4. 各赛道 📌🔍💡
- 📌 最新动态：**2-3 个核心事件，每个一句话**
- 🔍 洞察发现：**1 句话点到机制层面**
- 💡 落地行动：**1-2 个关键动作，每个一句话**
- 🟡弱信号：如有，融入 📌 或 💡 一行带过

### 5. ⭐ GitHub 推荐
- **恰好 3 个**（每个赛道 1 个、项目不重复）；多推一个同样判违规
- 项目名 + ⭐数 + 一句话说明
- **不要 📝💡 两行格式**（那是完整版的）
- 示例：`microsoft/autogen ⭐60.7K：多 Agent 编排，搭企业流水线可插人工审批。`

### 6. 📊 共识与分歧
- 各一句话结论
- **禁止出现具名事件/品牌/数字**

### 7. 空行铁律（微信渲染，最容易漏）
微信把「单换行」合并成同一段，只有**空行**才真的换行。所以摘要里**任意两个非空行之间必须有一个空行**：

- 段标题（`📋` / `🎯` / `🤖` / `💼` / `🎨` / `⭐` / `📊`）上下各空一行
- 每个 `•` 之间空行（🎯 三条要点）
- 每个 `●` 之间空行（⭐ 三个项目）
- 同赛道 `📌` / `🔍` / `💡` 之间空行 —— **这里最容易漏**
- `**🔵 共识解读**` 与 `**🔴 分歧解读**` 之间空行

反例（2026-09-20 实际投递，用户端显示成一整坨，用户直接报障）：
```
🤖 AI产业技术
📌 …（无空行）
🔍 …（无空行）
💡 …
⭐ GitHub推荐
● 项目A（无空行）
● 项目B
📊 共识与分歧
**🔵 共识解读** …
**🔴 分歧解读** …
```
由 `daily_briefing_check.py` 的 E13 逐行扫描（任意两个非空行相邻即报 error），不再靠人眼。

## 反例 vs 正例

### ❌ 反例（太冗长）
```
🎯 今天要点
• 推理算力进入「自研芯片+超大规模订单」双轨竞赛，模型推理成本与供给格局正在重写（OpenAI Jalapeño 自研推理芯片、Amazon 三倍追加 NVIDIA 订单、Anthropic 450 亿美元算力协议）。
```
问题：90 字 + 括号补充 + 一口气塞 3 个事件

### ✅ 正例（扫读友好）
```
🎯 今天要点
• 企业 GenAI 年度支出达 370 亿美元，同比增长逾三倍，Agent 落地进入规模化。
• 多家头部厂商同步把 Agent 治理、编排、成本控制做成平台级能力。
• 模型密集更新：旗舰+高性价比同日发布，编码代理走向独立产品。
```
特点：每条 ≤30 字，纯事实，无括号，一眼扫完

### ❌ 反例（赛道段落太长）
```
💼 企业AI应用
咨询与技术服务巨头联合头部模型商扩大合作，把旗舰模型通过前者的客户网络规模化部署到企业一线，是「模型能力×交付渠道」的企业级落地样板。云厂商将制造场景的代理式 AI 从「看板分析」推进到「自主决策」...
```
问题：一段话 126 字，读不完

### ✅ 正例（赛道段落精简）
```
💼 企业AI应用
📌 咨询巨头×模型商扩大合作规模化部署。云厂商制造代理从看板推进到自主决策。统一 Agent 平台覆盖法律金融行业版。
🔍 企业落地胜负手从「模型智商」转向「交付网络+行业模板+成本护栏」组合。
💡 参考行业版 Agent 平台搭内部助手。🟡弱信号：Agent FinOps 刚起步。
```
特点：📌 3 个事件各一句话，🔍 1 句机制洞察，💡 1 行行动+弱信号

## 生成检查清单

写完微信摘要版后自检：
1. [ ] CJK ≤ 600？
2. [ ] 🎯 要点无括号补充？
3. [ ] 每条 • ≤ 35 字？
4. [ ] 每赛道 📌 ≤ 3 句话？
5. [ ] 无 📖推荐阅读？
6. [ ] ⭐ GitHub 是一行格式、且**恰好 3 个**（每赛道 1 个、不重复）？
7. [ ] 📊 共识分歧无具名事件/品牌？
8. [ ] **任意两个非空行之间都有空行**（尤其 📌/🔍/💡、● 之间）？
